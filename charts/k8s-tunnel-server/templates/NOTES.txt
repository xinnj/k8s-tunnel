prefix and Password are generated on install and preserved on upgrade, so they are not printed
here. Hand the four values above to whoever needs them, out of band.

Rendering without cluster access -- `helm template`, Argo CD, Flux -- must pin them with
--set pathPrefix=... --set basicAuth.password=..., or it mints a new prefix on every run.
